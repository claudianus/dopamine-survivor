프레임워크도, 이미지·오디오 에셋도 없습니다 — 모든 그래픽과 사운드가 코드에서 실시간 생성됩니다.

## 🎮 게임 소개

- **무한 프로시듀럴 월드** — 시드 기반 심플렉스 노이즈로 초원 · 흑림 · 설원 · 사막 · 화산 · 도파민 광산 등 **10종 바이옴**이 끝없이 생성. 같은 시드 = 같은 월드!
- **도파민 폭발 연출** — 파티클 파열, 화면 흔들림, 데미지 숫자, 크리티컬, 콤보, 레벨업 폭죽, 슬롯머신 보물 상자, 보스 등장 레터박스까지!
- **9종 무기 × 5레벨 → 진화** — 매직 볼트, 궤도 검, 번개, 도파민 오라, 부메랑, 유탄 포, 레이저 창, 블랙홀, 천벌 망치. 만렙 무기는 상자에서 슈퍼 무기로 **진화**!
- **11종 패시브 × 5레벨** — 파워, 공속, 질주, 생명, 자석, 치명, 지혜, 재생, 행운, 탐욕, 가시갑주
- **보스 4종** — 5분 슬라임 킹, 10분 전갈 왕, 15분 서리 거인, 20분 최종 보스 **도파민 데몬**
- **20분 생존 → 승리!** 무한 연결 퀘스트, 월드 이벤트(유성우·젬비·광란의 밤·상인 정령), POI(보물 둥지·도파민 샘·혈천 의식)가 여정을 채웁니다
- **🌊 심층부 + 🌟 황금 목적지** — 스폰점에서 멀어질수록 젬·엘리트·상자율이 상승하고, 황금빛 비컨을 따라가면 거리에 비례한 잭팟! 바이옴 첫 발견에도 젬 분수+상자 보상

### 🎰 도파민 카지노 시스템

슬롯머신의 심리 엔진을 게임 언어로 번역한 중독성 레이어:

- **🎰 도파민 잭팟 게이지** — 킬로 조금씩 충전되는 런 간 영구 게이지. 100% 도달 시 다음 상자가 **MEGA CHEST**(8릴·진화 2개 확정)로 승격
- **스킬스톱 릴** — 상자 슬롯머신의 릴을 탭하면 즉시 정지. 슬롯의 "스톱 버튼" 통제감
- **😈 저주받은 상자** — 확정 보상 vs 저주를 걸고 2배(실패하면 젬 자루만). 진짜 배팅 순간
- **🎲 리롤 / 🚫 밴시시** — 레벨업 카드 다시 뽑기 1회 + 마지막 카드 이번 런 영구 제거
- **✨ 골든 몹 (0.3%)** — 예고 없이 나타나는 황금 변이. 잡으면 GOLDEN KILL 잼 분수
- **BIG WIN 세레머니** — 100/500/1000/2500킬 마일스톤마다 풀스크린 BIG→MEGA→EPIC WIN 티어 연출
- **💓 하트비트** — 러시 게이지 90%+에서 심장박 사운드. "릴이 멈추기 직전"의 긴장 상시 유지
- **🎁 pity 시스템** — 엘리트가 상자를 3연속 안 떨구면 확정 드랍 (보상 바닥 보장)
- **💀 near-miss 사망 리캡** — "보스 체력 4% 남기고 사망", "진화 재료는 모였다" 등 아까움 목록
- **⏰ 최후의 60초** — 19분부터 드랍 3배 + 유성우 + 음악 클라이맥스. 시간 압축 피날레
- **🪙 도파민 칩 상점** — 런 종료 시 점수→칩 환전, 영구 버프 5종(선물 무기·체력·선술투자·잭팟 가속·리롤+1) 구매
- **📅 오늘의 시드 & 🔥 연속 출석** — 날짜 파생 데일리 시드로 모두가 같은 월드에서 경쟁, 연속 접속은 칩 보너스

## 🕹️ 조작

| 동작 | PC | 모바일 · 태블릿 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 드래그 (가상 조이스틱) |
| 줌 | 마우스 휠 | 두 손가락 핀치 |
| 도파민 러시 | SPACE (게이지 최대 시) | ⚡ 버튼 |
| 레벨업 선택 | 클릭 / 1~3 | 탭 |
| 일시정지 | ESC / P | ⏸️ 버튼 |
| 음소거 | M | 🔊 버튼 |
| 전체화면 | F / ⛶ 버튼 | ⛶ 버튼 (지원 기기) |

> 💡 **팁:** 미니맵 ◆ 표식을 따라가면 이벤트 존이 있습니다. 도파민 샘에서 충전하고, 광산 도적(💰)을 잡으면 젬 자루가 터집니다.

## 🚀 로컬 실행

빌드 과정이 없습니다. 정적 파일 서빙만 하면 됩니다:

```bash
npx http-server -p 8080   # 또는 아무 정적 서버로 서빙
# → http://localhost:8080/ (랜딩), http://localhost:8080/play.html (게임)
```

시드 공유 플레이: `play.html?seed=12345` — 같은 시드는 같은 월드가 보장됩니다.

## 🛠️ 기술 스택

- 순수 **Canvas 2D** + Vanilla JS (ES2020, 의존성 0개)
- 심플렉스 노이즈 6종 바이옴 생성, 청크 단위 오프스크린 캔버스 캐싱
- 바이옴/지형 속성 타일 캐싱 — 적 AI·스폰에서 프레임당 수천 회의 노이즈 계산을 O(1) 조회로
- 공간 해시 그리드 충돌 최적화(대형 적 반경 패딩 포함), 다이내믹 라이팅(라이트맵 multiply + 컬러 블룸)
- 픽셀 브라이트패스 블룸, 색수차, 쇼크웨이브, 필름 그레인 포스트FX
- WebAudio 하이브리드 사운드 (Kenney CC0 샘플 15종 + 절차적 합성 레이어, 컨볼버 리버브 마스터링)
- Am–F–C–G 프로그레션 적응형 BGM (패드·심장박 베이스·햇·아르페지오, 긴장도 3단계 편곡)
- **적응형 품질 시스템** — 🥔/⚖️/✨ 3단계 + FPS 감지 자동 전환으로 스마트폰에서도 60fps 목표
- 히트스톱 이중 축 설계 — 게임 시간은 실시간으로 흐르고 시각 임팩트만 슬로모션 (스폰 스케줄 왜곡 없음)
- 반응형 UI + 가상 조이스틱 + 햅틱 피드백, 세이프에어리어 대응

### 🧪 안정성

- 상자 슬롯머신 타이머 경합 방지(재오픈 시 이전 티커 정리 + DOM 연결 가드), 레벨업 카드 이중 선택·키 홀드 연타 가드
- 사파리 프라이빗 모드 등 localStorage 접근 예외 환경 대응 래퍼
- 게임오버·재시작 시 모든 오버레이/러시 상태 정리 — 이전 런이 새 런에 새는 것을 차단
- Node VM 스모크 테스트로 20분 풀런(보스 4종 스폰 → 승리 엔딩)을 자동 검증: 크래시 0회
