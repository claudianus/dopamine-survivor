무한 프로시듀럴 맵에서 벌어지는 도파민 폭발 서바이벌 게임!
뱀파이어 서바이버 스타일의 자동 전투 로그라이트를 **순수 Canvas 2D + Vanilla JS**로 구현했습니다.
프레임워크도, 이미지·오디오 에셋도 없습니다 — 모든 그래픽과 사운드가 코드에서 실시간 생성됩니다.

## 🎮 게임 소개

- **무한 프로시듀럴 월드** — 시드 기반 심플렉스 노이즈로 초원 · 흑림 · 설원 · 사막 · 화산 · 도파민 광산 등 **10종 바이옴**이 끝없이 생성. 같은 시드 = 같은 월드!
- **도파민 폭발 연출** — 파티클 파열, 화면 흔들림, 데미지 숫자, 크리티컬, 콤보, 레벨업 폭죽, 슬롯머신 보물 상자, 보스 등장 레터박스까지!
- **9종 무기 × 5레벨 → 진화** — 매직 볼트, 궤도 검, 번개, 도파민 오라, 부메랑, 유탄 포, 레이저 창, 블랙홀, 천벌 망치. 만렙 무기는 상자에서 슈퍼 무기로 **진화**!
- **11종 패시브 × 5레벨** — 파워, 공속, 질주, 생명, 자석, 치명, 지혜, 재생, 행운, 탐욕, 가시갑주
- **보스 4종** — 5분 슬라임 킹, 10분 전갈 왕, 15분 서리 거인, 20분 최종 보스 **도파민 데몬**
- **20분 생존 → 승리!** 무한 연결 퀘스트, 월드 이벤트(유성우·젬비·광란의 밤·상인 정령), POI(보물 둥지·도파민 샘·혈천 의식)가 여정을 채웁니다

## 🕹️ 조작

| 동작 | PC | 모바일 · 태블릿 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 드래그 (가상 조이스틱) |
| 줌 | 마우스 휠 | 두 손가락 핀치 |
| 도파민 러시 | SPACE (게이지 최대 시) | ⚡ 버튼 |
| 레벨업 선택 | 클릭 / 1~3 | 탭 |
| 일시정지 | ESC / P | ⏸️ 버튼 |
| 음소거 | M | 🔊 버튼 |

> 💡 **팁:** 미니맵 ◆ 표식을 따라가면 이벤트 존이 있습니다. 도파민 샘에서 충전하고, 광산 도적(💰)을 잡으면 젬 자루가 터집니다.

## 🚀 로컬 실행

빌드 과정이 없습니다. 정적 파일 서빙만 하면 됩니다:

```bash
npx http-server -p 8080   # 또는 아무 정적 서버로 서빙
# → http://localhost:8080/ (랜딩), http://localhost:8080/play.html (게임)
```

시드 공유 플레이: `play.html?seed=12345` — 같은 시드는 같은 월드가 보장됩니다.

## 🛠️ 기술 스택

- 순수 **Canvas 2D** + Vanilla JS (ES2020, 의존성 0개)
- 심플렉스 노이즈 6종 바이옴 생성, 청크 단위 오프스크린 캔버스 캐싱
- 공간 해시 그리드 충돌 최적화, 다이내믹 라이팅(라이트맵 multiply + 컬러 블룸)
- 픽셀 브라이트패스 블룸, 색수차, 쇼크웨이브, 필름 그레인 포스트FX
- WebAudio 절차적 사운드 엔진 (효과음 20종 + 다크 앰비언트 BGM 실시간 합성)
- **적응형 품질 시스템** — 🥔/⚖️/✨ 3단계 + FPS 감지 자동 전환으로 스마트폰에서도 60fps 목표
- 반응형 UI + 가상 조이스틱 + 햅틱 피드백, 세이프에어리어 대응

```
index.html      # 랜딩 페이지 (소개 + 게임 시작)

style.css       # 게임 네온 다크 스타일
404.html        # Pages 404

  audio.js      # WebAudio 절차적 효과음 + BGM
  map.js        # 프로시듀럴 바이옴/청크/장식/POI/미니맵
  entities.js   # 적 20종 · 엘리트 · 보스 4종 AI · 지형 기믹 · 결정
  weapons.js    # 무기 9종 + 진화 + 투사체 시스템
  upgrades.js   # 패시브 11종 · 레벨업 카드 · 상자 슬롯머신
  game.js       # 게임 루프 · 렌더링 · 라이팅 · HUD · 퀘스트 · 이벤트 · 입력
```
