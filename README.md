# 💎 도파민 서바이버 (Dopamine Survivor)

무한 프로시듀럴 맵에서 벌어지는 도파민 폭발 서바이벌 게임!
뱀파이어 서바이버 스타일의 자동 전투 로그라이트를 순수 Canvas + Vanilla JS로 구현했습니다.

**▶ 플레이:** GitHub Pages가 활성화되면 `https://<사용자명>.github.io/dopamine-survivor/` 에서 바로 즐길 수 있습니다.

## 🎮 게임 소개

- **무한 프로시듀럴 월드** — 시드 기반 심플렉스 노이즈로 초원 · 숲 · 사막 · 설원 · 화산 · 도파민 광산 바이옴이 절차적으로 생성됩니다. 같은 시드 = 같은 월드!
- **도파민 폭발 연출** — 파티클 폭발, 화면 흔들림, 데미지 숫자, 크리티컬, 콤보 카운터, 레벨업 폭죽, 슬롯머신 보물 상자까지!
- **7종 무기 × 5레벨** — 매직 볼트, 궤도 검, 번개, 도파민 오라, 부메랑, 유탄 포, 레이저 창
- **9종 패시브** — 공격력, 공속, 질주, 생명력, 자석, 치명타, 지혜, 재생, 행운
- **보스 4종** — 5분 슬라임 킹, 10분 전갈 왕, 15분 서리 거인, 20분 최종 보스 **도파민 데몬**
- **20분 생존 → 승리!** 낮/밤이 흐르고 몰려오는 웨이브를 버티세요

## 🕹️ 조작

| 동작 | 방법 |
|---|---|
| 이동 | WASD / 방향키 / 모바일 터치 드래그 |
| 공격 | 자동 |
| 레벨업 선택 | 클릭 또는 1~3 키 |
| 일시정지 | ESC / P |

## 🚀 로컬 실행

빌드 과정이 없습니다. 정적 파일만 있으면 됩니다:

```bash
npx http-server -p 8080   # 또는 아무 정적 서버로 index.html 서빙
```

## 🛠️ 기술 스택

- 순수 **Canvas 2D** + Vanilla JS (프레임워크 · 에셋 파일 없음 — 모든 그래픽/사운드가 코드로 생성)
- 심플렉스 노이즈 3종(고도/습도/기온) 바이옴 생성, 청크 단위 오프스크린 캔버스 캐싱
- 공간 해시 그리드 충돌 최적화, 오브젝트 풀링
- WebAudio 절차적 사운드 엔진 (효과음 전부 실시간 합성)
- 모바일 터치 조이스틱 지원, 반응형 UI

## 📁 구조

```
index.html      # 마크업 + 오버레이 UI
style.css       # 네온 다크 스타일
js/
  core.js       # 수학 · 시드 RNG · 심플렉스 노이즈
  audio.js      # WebAudio 절차적 효과음
  map.js        # 프로시듀럴 바이옴/청크/장식/미니맵
  entities.js   # 적 12종 · 엘리트 · 보스 4종 AI
  weapons.js    # 무기 7종 + 투사체 시스템
  upgrades.js   # 패시브 · 레벨업 카드 · 상자 슬롯머신
  game.js       # 게임 루프 · 렌더링 · HUD · 입력
```

행운을 빕니다 — 도파민은 쏟아질 테니까요. 💥
